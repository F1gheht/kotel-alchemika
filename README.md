# Котёл алхимика · Alchemist's Cauldron

Калькулятор крафта зелий и перекрафта ресурсов для **Albion Online**: рецепты, иконки, живые цены по городам, расчёт профита и список закупки.

*Crafting and refining calculator for Albion Online: recipes, icons, live market prices by city, profit and a shopping list. English UI included.*

## Скачать

Установщик для Windows — в разделе **[Releases](../../releases/latest)**: `KotelAlchemika-Setup.exe`.

- Ставится в профиль пользователя, права администратора не нужны.
- Повторный запуск новой версии установщика обновляет приложение, план и настройки сохраняются.
- Удаление — «Параметры → Приложения».
- Нужен Microsoft Edge WebView2 (в Windows 10/11 обычно уже есть).
- Установщик не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

## Что умеет

- **Зелья:** все 43 зелья, рецепты из игровых файлов, расход фокуса.
- **Перекрафт:** кожа, слитки, ткань, доски, каменные блоки; T2–T8, зачарование .0–.4; расчёт всей цепочки от T2.
- **Возврат ресурсов:** галочки «Профильный город» и «Фокус».
- **Цены:** [Albion Online Data Project](https://www.albion-online-data.com/), средняя за 7 дней или текущая; автообновление; серверы Europe / Americas / Asia.
- **План крафта** и **список закупки** по городам; русский и английский интерфейс; обучение при первом запуске.

## Как устроено

| Папка | Что внутри |
|---|---|
| `web/` | Интерфейс: `template.html` (код страницы), `data.json` (рецепты, названия, иконки, снимок цен), `index.html` (собранная страница) |
| `app/` | Приложение на Go: окно WebView2 + локальный сервер (цены, иконки, сохранение настроек) |
| `setup/` | Установщик на Go |
| `tools/` | Скрипты: выгрузка рецептов из [ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps), рисование иконки |

## Сборка

Нужны Go 1.24+ и Python 3. Готовые файлы появятся в `dist/`.

```
build.bat        # Windows
./build.sh       # Linux / macOS (собирает .exe для Windows)
```

## Источники данных

Цены — Albion Online Data Project (собираются игроками). Рецепты и названия — [ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps). Иконки предметов — render.albiononline.com.

Неофициальный фанатский проект. Albion Online, названия и иконки предметов принадлежат Sandbox Interactive.
